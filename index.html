🎯 Project Overview

A comprehensive Data Science capstone project that predicts bicycle rental demand in Washington DC based on weather conditions and temporal patterns. The project achieves 86.25% prediction accuracy (R²) using a tuned Random Forest model.

Key Achievement: Production-ready machine learning model capable of forecasting daily bike rental demand with an average error of approximately 498 bikes per day.

🚀 Highlights

📊 Complete Pipeline

Data cleaning → EDA → Feature engineering → Model training → Deployment

🤖 7 ML Models

Random Forest, Gradient Boosting, Neural Networks, Ridge, Lasso, Linear, Decision Tree

🔬 Advanced Analysis

K-Means clustering, PCA, user segmentation, time series analysis

📈 Business Value

$200K-500K annual savings potential, 60% reduction in shortages

🔬 Methodology

  • Data Preparation: Cleaned and validated 731 daily records (zero missing values)
  • Exploratory Analysis: Comprehensive correlation analysis and visualizations
  • Feature Engineering: Created 13 new features (rolling averages, lagged features, cyclical encodings)
  • Model Development: Trained and compared 7 machine learning algorithms
  • Optimization: GridSearchCV with 5-fold cross-validation
  • Evaluation: Comprehensive model comparison and residual analysis

🔑 Key Findings

  • Top Predictor: Previous day's rentals (63.42% feature importance)
  • Temperature Impact: Strong positive correlation (+0.63) with rental demand
  • Seasonal Peak: Fall season shows highest demand (5,644 rentals/day)
  • Weather Effect: Clear weather increases rentals by 63% vs rainy days
  • Growth Trend: 73.6% year-over-year increase (2011→2012)
  • User Segmentation: Registered users account for 81% of rentals
  • Demand Clusters: Identified 4 distinct rental patterns via K-Means
